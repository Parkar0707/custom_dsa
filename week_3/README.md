## 📊 Complexity Cheat Sheet

### Common DP Complexities:
- **1D DP**: O(n) time, O(n) or O(1) space
- **2D DP**: O(n²) or O(n×m) time and space
- **Bitmask DP**: O(2^n × n) time for TSP-like problems
- **Tree DP**: O(n) time for tree with n nodes

### Greedy Algorithms:
- **Sorting**: O(n log n)
- **Interval scheduling**: O(n log n) with sorting
- **Huffman coding**: O(n log n) with heap

### Mathematical Algorithms:
- **Fast exponentiation**: O(log n)
- **Sieve**: O(n log log n)
- **GCD**: O(log min(a,b))
