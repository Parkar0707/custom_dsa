## 💡 Tips for Success

### Understanding Before Coding
1. Read the problem statement carefully
2. Study the core concepts section
3. Trace through the algorithm intuition example
4. Identify the data structures needed
5. Think about edge cases

### Implementation Strategy
1. Start with the simplest approach
2. Identify time/space bottlenecks
3. Optimize gradually
4. Test on provided examples
5. Handle edge cases

### Testing Checklist
- [ ] Empty input
- [ ] Single element
- [ ] Large input
- [ ] Boundary conditions
- [ ] Edge cases mentioned in problem

### Debugging Tips
- Print intermediate states
- Trace through examples by hand
- Use assertions for invariants
- Verify time/space complexity
- Compare with expected output
