CONCEPT INVENTORY (10 MAJOR TECHNIQUES)
═════════════════════════════════════════════════════════════════════════════

✓ 1. SLIDING WINDOW TECHNIQUE
    Purpose: Process consecutive elements efficiently
    Problems: #2 (Telescope), #8 (DNA)
    Key Idea: Move window by removing left, adding right (avoid recalculation)
    Time: O(n*k*log k) for window size k
    
✓ 2. TWO-POINTER TECHNIQUE  
    Purpose: Manipulate array in-place efficiently
    Problems: #3 (Signals), #5 (Memory)
    Key Idea: One pointer reads, one pointer writes (or opposite directions)
    Time: O(n), Space: O(1)
    
✓ 3. HASHING & HASH TABLES
    Purpose: Constant-time lookups and deduplication
    Problems: #3 (Signals), #8 (DNA)
    Key Idea: Store seen values for O(1) membership testing
    Time: O(n) average
    
✓ 4. KADANE'S ALGORITHM
    Purpose: Find maximum sum subarray
    Problems: #4 (Solar Panel)
    Key Idea: At each position, decide: extend previous or start fresh
    Time: O(n), Space: O(1)
    
✓ 5. PREFIX SUM
    Purpose: Answer range sum queries efficiently
    Problems: #6 (Rover)
    Key Idea: Precompute cumulative sums for O(1) range queries
    Time: O(n) preprocessing, O(1) query
    
✓ 6. QUICKSELECT ALGORITHM
    Purpose: Find kth smallest/largest without full sorting
    Problems: #7 (Asteroids)
    Key Idea: Partition array, recursively search relevant half
    Time: O(n) average, O(n²) worst case
    
✓ 7. HEAPS & PRIORITY QUEUES
    Purpose: Maintain min/max order efficiently
    Problems: #7 (Asteroids), #10 (Sensor Fusion)
    Key Idea: Log(n) insertion/removal, O(1) peek min/max
    Time: O(log n) per operation
    
✓ 8. DYNAMIC PROGRAMMING & LCS
    Purpose: Optimize overlapping subproblems
    Problems: #8 (DNA)
    Key Idea: Build solutions from bottom-up, store intermediate results
    Time: O(m*n) for two strings
    
✓ 9. CIRCULAR ARRAYS & CYCLIC BUFFERS
    Purpose: Reuse fixed memory space with wrapping
    Problems: #9 (Packets)
    Key Idea: Use modulo arithmetic to wrap indices
    Time: O(n), Space: O(1)
    
✓ 10. K-WAY MERGE ALGORITHM
     Purpose: Combine k sorted sequences efficiently
     Problems: #10 (Sensor Fusion)
     Key Idea: Use heap to always get minimum from k lists
     Time: O(n log k)

PROBLEMS & REQUIRED CONCEPTS MAP
═════════════════════════════════════════════════════════════════════════════

PROBLEM #2: Telescope Image Sensor Calibration
  Main Concept: Sliding Window
  Secondary: Sorting, Median calculation
  Task: Remove hot pixels using median filtering
  Approach: Maintain window of size k, calculate median as you slide
  Key Challenge: Efficiently computing median (not just sorting each window)

PROBLEM #3: Radio Telescope Signal Deduplication  
  Main Concepts: Hashing, Two-Pointer
  Secondary: Array manipulation
  Task: Find unique signals from stream with duplicates
  Approach: Either use HashSet for O(1) dedup OR sort + two-pointer
  Key Challenge: Handle both order preservation and efficiency

PROBLEM #4: Solar Panel Array Optimization
  Main Concept: Kadane's Algorithm (Maximum Subarray Variant)
  Secondary: Dynamic Programming thinking
  Task: Maximize power gain with contiguous panel rotations
  Approach: Track max ending here, max so far - decide to extend or restart
  Key Challenge: All negative numbers, constraint on segment size

PROBLEM #5: Spacecraft Memory Compaction
  Main Concepts: Two-Pointer, Array Manipulation
  Secondary: In-place modification
  Task: Defragment memory blocks in O(1) space
  Approach: Read pointer scans, write pointer marks where non-free goes
  Key Challenge: Moving elements in-place without extra arrays

PROBLEM #6: Planetary Rover Path Validation
  Main Concepts: Prefix Sum
  Secondary: Coordinate systems, boundary checking
  Task: Verify rover movements stay within bounds
  Approach: Count movements in each direction, check cumulative position
  Key Challenge: Handling 2D coordinates and incremental validation

PROBLEM #7: Asteroid Belt Density Mapping
  Main Concepts: Quickselect, Heaps
  Secondary: Distance metrics, comparison functions
  Task: Find k closest asteroids efficiently
  Approach: Either quickselect kth smallest OR max-heap of size k
  Key Challenge: Choosing between quickselect (avg O(n)) vs heap (O(n log k))

PROBLEM #8: DNA Sequence Mutation Detection
  Main Concepts: Dynamic Programming, Longest Common Subsequence
  Secondary: Sliding Window (optimization variant), Hashing
  Task: Find longest common genetic material
  Approach: Build DP table where dp[i][j] = LCS length of first i and j chars
  Key Challenge: Reconstruction of actual LCS string, space optimization

PROBLEM #9: Network Packet Reordering
  Main Concepts: Circular Arrays, Cyclic Buffers
  Secondary: Modulo arithmetic
  Task: Reorder out-of-sequence packets efficiently
  Approach: Use circular buffer with sequence number windowing
  Key Challenge: Handling wrap-around, detecting duplicate/out-of-window packets

PROBLEM #10: Sensor Fusion Timestamp Alignment
  Main Concepts: K-way Merge, Heaps
  Secondary: Priority queues, multi-source data
  Task: Merge k sorted sensor data streams
  Approach: Min-heap of (timestamp, stream_id, index) tuples
  Key Challenge: Coordinating multiple streams at different rates

DECISION FLOWCHART: WHICH CONCEPT TO USE?
═════════════════════════════════════════════════════════════════════════════

Problem involves...?

→ Consecutive elements/windows?
  └─ Sliding Window

→ Array in-place modification?
  └─ Two-Pointer

→ Finding duplicates/seen values?
  └─ Hashing

→ Maximum/minimum sum subarray?
  └─ Kadane's Algorithm

→ Range sum queries?
  └─ Prefix Sum

→ Finding kth smallest/largest?
  ├─ k close to n? → Quickselect
  └─ k << n? → Heap

→ Complex string/sequence problem?
  └─ Dynamic Programming (LCS, LIS, etc.)

→ Fixed circular buffer/bounded memory?
  └─ Circular Array + Modulo

→ Merging multiple sorted sequences?
  └─ K-way Merge with Heap
