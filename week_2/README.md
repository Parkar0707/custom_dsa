# Week 2: Trees, Graphs & Advanced Data Structures

## 📚 Course Overview

This week covers advanced data structures and algorithms focusing on:
- **Trees**: Binary trees, BSTs, balanced trees
- **Graphs**: Traversal, shortest paths, spanning trees, advanced algorithms
- **Heaps & Priority Queues**: Event simulation and optimization

## 📋 Structure

Each day is organized into 10 problems with detailed explanations:
- **Problem Directories**: Named as `d[day]p[problem]` (e.g., `d08p01`)
- **README.md**: Contains problem statement, concepts, examples, and hints
- **No Answers**: Academic integrity maintained—guides to thinking, not solutions

## 🎯 How to Use This Material

### For Each Problem:
1. **Read the Problem Statement**: Understand what needs to be accomplished
2. **Study Core Concepts**: Learn the algorithm/data structure theory
3. **Work Through Examples**: Follow the step-by-step walkthroughs
4. **Understand the Algorithm Outline**: See the pseudocode structure
5. **Try Implementation Hints**: Use as guide, not solution
6. **Test Thoroughly**: Consider all test cases
7. **Think About Follow-ups**: Explore extensions and variations

### Learning Path:
- **Sequential**: Work through days 8-14 in order
- **Thematic**: Group by concept (e.g., all traversal problems together)
- **Problem-focused**: Pick real-world scenarios that interest you

## 💡 Key Principles

✅ **DO**:
- Work through problems systematically
- Think before coding
- Implement from pseudocode, not memory
- Test edge cases thoroughly
- Understand, don't memorize

❌ **DON'T**:
- Look at answers first
- Copy implementations without understanding
- Skip the "why" behind algorithms
- Ignore complexity analysis
- Only code, without thinking

## 📊 Complexity Cheat Sheet

### Common Complexities:
- **Array operations**: O(n)
- **Balanced BST operations**: O(log n)
- **Graph traversal**: O(V + E)
- **Sorting**: O(n log n)
- **Floyd-Warshall**: O(V³)
- **Dijkstra**: O((V + E) log V)

## 🔗 Related Topics

- **Dynamic Programming**: Complements many graph problems
- **Greedy Algorithms**: Used in MST and scheduling
- **NP-Complete Problems**: TSP, matching problems
- **Approximation Algorithms**: For hard optimization problems
